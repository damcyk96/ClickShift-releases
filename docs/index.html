How it works

Three steps before the ride.

  1. 01

    Wake the Clicks

    Open CogShift and press a button on each Click. They connect by themselves; no pairing in system settings.

  2. 02

    Connect in MyWhoosh

    CogShift appears in MyWhoosh's Device Connection screen as a controller. Select it once.

  3. 03

    Ride

    Run the short built-in test so CogShift picks the button layout that fits your Clicks, then shift.

MyWhoosh can run on the same computer or on another device in the same network, such as an Apple TV, an iPad or a second laptop.

Download

Free for macOS and Windows.

macOS

Tested with Click V2

Apple Silicon Mac (M1 or later) with Bluetooth.

Download ClickShift-macos.zip
Install on macOS
  1. Unzip the file and move ClickShift.app to Applications.
  2. Open it. macOS refuses the first time, because the app is not yet notarized by Apple.
  3. Open System Settings → Privacy & Security, scroll to Security and select Open Anyway. This is needed once per version.
  4. Allow Bluetooth and Local Network access when macOS asks.

Windows

First version

Windows 10 (1809 or later) or Windows 11 with Bluetooth LE, and Apple Bonjour.

Download ClickShift-windows.zip
Install on Windows
  1. Install Bonjour Print Services for Windows unless you already have Bonjour (it also comes with iTunes). MyWhoosh on Windows finds CogShift through it.
  2. Unzip the file and run ClickShift.exe from the unzipped folder. Keep the other files next to it.
  3. The app is not signed, so SmartScreen may warn on the first start: select More info → Run anyway.
  4. If Windows Firewall asks, allow access on private networks.

Don't pair the Clicks in Windows Bluetooth settings; CogShift connects to them itself.

What you need

Clicks, MyWhoosh and one network.

  • Zwift Click V2 controllers. The original single Click is supported too, but has not been tried on real hardware yet.
  • MyWhoosh with Virtual Shifting (MyShift) enabled and your trainer paired directly with MyWhoosh.
  • The same local network for CogShift and MyWhoosh, or both on one computer.
  • Only one app on the Clicks. Quit Zwift or any other app connected to them first; a Click talks to one app at a time.

Help

Good to know.

The left Click connects but doesn't shift

The left Click can stay connected while it stops reporting button presses. Run the test in CogShift: it switches to 1 Click mode, where the right Click's + shifts up and its B shifts down. To get the left one back, pair both Clicks in Zwift, quit Zwift completely, reconnect them in CogShift and run the test again.

MyWhoosh lost CogShift after I restarted it

MyWhoosh does not reconnect by itself. Connect CogShift again in MyWhoosh's Device Connection screen.

Why do macOS and Windows warn about the app?

The desktop apps are not yet signed with a paid publisher certificate, so both systems ask you to confirm the first start. The install steps above show where.

Does CogShift control my trainer?

No. MyWhoosh keeps controlling the trainer and its resistance; CogShift only sends the button presses.

Something doesn't work

Open an issue and attach the log (Logs → Copy logs in the app). The log can contain local IP addresses and Bluetooth device identifiers, so review it before posting.
